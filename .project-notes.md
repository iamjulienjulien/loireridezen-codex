## Démarrage

Prérequis : Node.js 20.9 ou supérieur et pnpm. Le projet utilise pnpm exclusivement.

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```

Configuration locale minimale :

```dotenv
CURRENT_ENV=development
SITE_URL=https://codex.loireridezen.bike
```

`CURRENT_ENV` accepte uniquement `development` ou `production`. Ne jamais ajouter de secret dans ce fichier de notes.

## Qualité de l’API

| Contrôle                            | Commande                                            |
| ----------------------------------- | --------------------------------------------------- |
| Valider le contrat Redocly          | `pnpm api:lint`                                     |
| Tester les formes publiques         | `pnpm api:test:contract`                            |
| Détecter les ruptures OpenAPI       | `pnpm api:contract:diff`                            |
| Vérifier les données éditoriales    | `SITE_URL=https://example.test pnpm api:data:check` |
| Vérifier la documentation           | `pnpm api:docs:check`                               |
| Tester la collection Bruno en local | `pnpm api:test:local`                               |
| Smoke test de production            | `pnpm api:test:smoke`                               |

`pnpm api:test:production` interroge réellement la production : l’utiliser uniquement quand ce contrôle externe est intentionnel.

## Repères d’architecture

```text
data/*.json
    ↓
src/registry + src/api/schemas
    ↓
src/app/<index> et src/app/api/v1
    ↓
interface web + réponses publiques validées par OpenAPI
```

- Les index visibles dépendent de `CURRENT_ENV` et de `src/registry/indexes.ts`.
- Les schémas Zod valident les données internes.
- Le contrat OpenAPI décrit les DTO publics et doit évoluer avec leurs tests.
- L’Atelier sert à comparer les composants et leurs variantes sans perturber les pages publiques.

## Avant de terminer une modification

- [ ] Vérifier le rendu local concerné.
- [ ] Lancer `pnpm lint`.
- [ ] Lancer `pnpm test`.
- [ ] Lancer `pnpm format:check`.
- [ ] Pour une modification API, lancer les contrôles de contrat adaptés.
- [ ] Pour une modification éditoriale, lancer `pnpm api:data:check`.
- [ ] Vérifier qu’aucun secret ou fichier `.env.local` n’est ajouté à Git.

## Worktrees

Un nouveau worktree ne partage ni `node_modules` ni les fichiers `.env.local` non suivis par Git :

```bash
pnpm install
cp /chemin/du/repo-principal/.env.local .env.local
```

Si le repo principal utilise déjà le port `3000`, lancer le worktree sur un autre port ou arrêter le premier serveur.
